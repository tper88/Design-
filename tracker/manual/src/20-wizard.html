The wizard has seven steps. You see them in the left bar: Start, Basics, Data, Tabs, Components, Alerts, Review & export.

  • Move between steps with ← Back and Next →, or click a step name in the left bar — in any order.
  • The wizard does not check anything along the way. You see every problem at once in the last step, in a red box that says what to fix.
  • At the bottom of the left bar there is a short hint for the current step.
  • The wizard does not save your work by itself. If you close the tab before downloading the files, the changes are lost. During longer sessions, download Download structure (.tracker.json) now and then.

How a preset picks columns. It recognises their role by type and name (English and Polish):

  • due date — a date column named like due, deadline, until, termin;

Preview

Opens the tracker in a window with sample data (24 made-up rows). Nothing is saved. Use it to look at the layout before saving.

Download tracker (.html) or Save tracker

Saves the tracker. Chrome asks where to save the file. The button in the top-right corner does the same.

Download structure (.tracker.json)

Saves the structure. It works even while there are problems — you can save unfinished work and come back to it.

Save BOTH files in the same folder The .html is the tracker, the .tracker.json is its structure. Without the .tracker.json every later change means building the tracker again. When you update an existing tracker, overwrite the old .html file in the same place, under the same name.
