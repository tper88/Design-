This chapter is for everyone who uses the tracker — including people who will never open the wizard. If you hand the tracker to a colleague, send them this chapter.

The tracker saves by itself. A second and a half after your last change the data goes into the file. You do not need to click anything. The save status is at the top, next to Save:

TextDotMeaning
Saved 14:32greenEverything is in the file. The last change was saved at that time.

  • Save or Ctrl+S saves at once. Without a file it opens the file choice.
  • Switching to another browser tab also forces a save.
  • If you close the tab with unsaved changes, Chrome asks whether you really want to leave — choose “Cancel” and wait for Saved.
  • If saving fails (e.g. the disk is full) you see a red message, Could not write the data file: …, and the status Unsaved changes. The data is still in the browser — free some space and click Save.

The which-version bar

Sometimes the file and the browser hold different data: someone changed the file on another computer while you were working in the browser. Then a red bar appears — The data file is newer than the browser copy or This file already holds data.

Load from file

The file wins. What is in the browser is replaced with the file's data.

Keep browser copy

The browser wins. The file is overwritten with the browser's version.

Download both

Not sure? It downloads both versions as JSON files to your Downloads folder so you can compare them. The bar stays until you choose one of the two options above.

Przeglądarka pamięta Twój plik, ale ze względów bezpieczeństwa po każdym jej zamknięciu prosi o zgodę na zapis. Dlatego po ponownym otwarciu trackera zobaczysz baner:

  1. Kliknij Reconnect.
  2. Chrome zapyta, czy pozwolić stronie edytować plik — kliknij „Edytuj plik” / „Allow”.
  3. Zobaczysz Connected — changes save automatically. Gotowe — do zamknięcia przeglądarki nie zapyta ponownie.
Najlepiej kliknąć Reconnect od razu po otwarciu. Jeśli jednak zaczniesz pracę wcześniej, nic nie przepadnie — po połączeniu Twoje zmiany zostaną zapisane do pliku.

Jeśli odmówisz, zobaczysz Without file access your changes stay in the browser only. Możesz połączyć się później: Save, Ctrl+S albo baner u góry.

The browser remembers your file, but for safety it asks for permission to save every time it has been closed. So when you open the tracker again you see a banner:

  1. Click Reconnect.
  2. Chrome asks whether to let the page edit the file — click “Edit file” / “Allow”.
  3. You see Connected — changes save automatically. Done — it will not ask again until you close the browser.
It is best to click Reconnect straight away. If you start working first, nothing is lost — once connected, your changes are written to the file.

If you refuse, you see Without file access your changes stay in the browser only. You can connect later: Save, Ctrl+S or the banner at the top.

Nowy wiersz

  1. Kliknij + Add row nad tabelą. Z prawej wysunie się panel z formularzem.
  2. Wypełnij pola. Pola z gwiazdką są obowiązkowe. Niektóre są już wypełnione (np. dzisiejsza data, Twoje imię).

Poprawianie w panelu

Kliknij wiersz — otworzy się panel ze wszystkimi polami (także tymi, których nie ma w tabeli). Popraw i kliknij Save changes. Delete row usuwa wiersz (po potwierdzeniu).

Zamknięcie panelu bez zapisu porzuca zmiany ✕, Esc albo kliknięcie obok panelu zamykają go bez pytania. Zawsze kończ przyciskiem Save changes albo Add row.

Szybka poprawka w komórce

Kliknij dwa razy komórkę — zamieni się w pole edycji. Enter zapisuje, Esc anuluje. Kolumny tak/nie zmieniasz jednym kliknięciem w kratkę, a długi tekst tylko w panelu.

Kropkowane podkreślenie

Wartość podkreślona kropkami nie pasuje do typu kolumny (np. „32.13.2026” w kolumnie daty, tekst w kolumnie liczb). Tracker jej nie zmienia ani nie kasuje — najedź myszą, żeby zobaczyć wyjaśnienie, i popraw wartość.

A new row

  1. Click + Add row above the table. A panel with a form slides in from the right.
  2. Fill in the fields. Fields with an asterisk are required. Some are already filled in (e.g. today's date, your name).
  3. Click Add row at the bottom of the panel.

Editing in the panel

Click a row — a panel opens with every field (including ones not shown in the table). Make your changes and click Save changes. Delete row deletes the row (after confirming).

Closing the panel without saving discards the changes ✕, Esc or clicking beside the panel close it without asking. Always finish with Save changes or Add row.

A quick fix in a cell

Double-click a cell — it turns into an input. Enter saves, Esc cancels. Yes/no columns change with one click on the box, and long text only in the panel.

A dotted underline

A value with a dotted underline does not fit the column type (e.g. “32.13.2026” in a date column, text in a number column). The tracker neither changes nor deletes it — hover to see the explanation, then correct the value.

Search…

Type part of a text — the table shows rows where it appears in any visible column.

Quick filters

Click e.g. Overdue — only overdue rows remain. Click again to switch it off. One works at a time.

Sorting

Click a column header: ascending. Again: descending. The arrow next to the header shows the direction.

Pages

Under the table there is a counter (“42 rows · page 1 of 1”) and page buttons.

When the filters find nothing you see Nothing matches your filters and a Clear filters button. With more than 500 matching rows the table shows the first 500 (the banner Showing the first 500 rows) — exports and totals still cover all of them.

Search, filters, sorting, the page and the selection are forgotten when the tracker is closed. It always opens on the first tab.

From the keyboard: Tab to a row's box and press Shift+F10.

  1. W Excelu zaznacz wiersze (najlepiej razem z nagłówkiem) i skopiuj: Ctrl+C.
  2. W trackerze otwórz zakładkę z tabelą, kliknij gdziekolwiek poza polem tekstowym i naciśnij Ctrl+V.
  3. Pojawi się okno Import rows. Sprawdź, czy każda kolumna z Excela trafia we właściwą kolumnę trackera. Kolumny, których nie chcesz, ustaw na — skip —.
  4. Kliknij Import N rows.
  • Z nagłówkiem kolumny są dopasowane po nazwach, w dowolnej kolejności. Bez nagłówka — po kolejności kolumn w tabeli; okno to napisze.
  • Daty i liczby są czytane według formatu wybranego w kreatorze. „06.10.2026”, „1 234,56 zł”, „PRAWDA” — wszystko zadziała, jeśli format zgadza się z Twoim Excelem.
  • Wartości, których nie da się odczytać, nie przepadają: trafiają do trackera tak, jak były, z kropkowanym podkreśleniem, a komunikat po imporcie mówi, ile ich było.
  • Pusta tabela ma też przycisk Paste from Excel — otwiera pole, w które wklejasz ręcznie.
Import nie sprawdza pól obowiązkowych. Puste kolumny, które mają wartość domyślną (dziś, Twoje imię), zostaną nią wypełnione.
  1. In Excel, select the rows (ideally with the header) and copy: Ctrl+C.
  2. In the tracker, open a tab with a table, click anywhere outside a text field and press Ctrl+V.
  3. The Import rows window appears. Check that each Excel column goes into the right tracker column. Set columns you do not want to — skip —.
  4. Click Import N rows.
  • With a header, columns are matched by name in any order. Without one, by the order of the table's columns; the window says so.
  • Dates and numbers are read in the format chosen in the wizard. “06/10/2026”, “£1,234.56”, “TRUE” — all work, as long as the format matches your Excel.
  • Values that cannot be read are not lost: they go in as they were, with a dotted underline, and the message after the import says how many there were.
  • An empty table also has a Paste from Excel button — it opens a box you paste into by hand.
The import does not check required fields. Empty columns that have a default (today, your name) are filled with it.

Karteczki

  • + Add note dodaje pustą karteczkę. Kliknij ją i pisz; zapisuje się, gdy klikniesz obok.
  • Kropki na dole zmieniają kolor, ✕ usuwa (po potwierdzeniu Delete this note?).
  • Karteczka przypięta do wiersza: otwórz wiersz i kliknij + Pin a note w sekcji Notes on this row. Widać ją tylko w tym wierszu, nie na tablicy.

Checklisty

  • Wpisz pozycję w polu New item, then Enter i naciśnij Enter. Jeśli obok jest pole daty, możesz od razu ustawić termin.
  • Kliknij kratkę, żeby odhaczyć. Kliknij tekst, żeby go poprawić. Kliknij termin, żeby go zmienić.
  • ✕ usuwa pozycję od razu, bez pytania.
  • Licznik w rogu pokazuje „zrobione / wszystkie”. W codziennej rutynie odhaczenia znikają następnego dnia.

Agenda

Agenda sama zbiera terminy z tabeli. Kliknij pozycję, żeby otworzyć jej wiersz.

Sticky notes

  • + Add note adds an empty note. Click it and type; it saves when you click elsewhere.
  • The dots at the bottom change the colour, ✕ deletes it (after confirming Delete this note?).
  • A note pinned to a row: open the row and click + Pin a note under Notes on this row. It shows only in that row, not on the board.

Checklists

  • Type an item in New item, then Enter and press Enter. If there is a date field beside it, you can set a due date straight away.
  • Click the box to tick an item. Click the text to edit it. Click the due date to change it.
  • ✕ deletes an item straight away, without asking.
  • The counter in the corner shows “done / total”. In a daily routine the ticks clear the next day.

Agenda

The agenda collects dates from the table by itself. Click an item to open its row.
