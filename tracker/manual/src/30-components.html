There are 9 kinds of component. Five of them calculate from data (KPI card, stat, chart, table, progress bar) — that is why they have a Dataset field. The other four (banner, agenda, sticky notes, checklist) work differently, as described below.

The same filter editor appears in counters, charts, banners, tables (fixed filter and quick filters) and alerts.

Each condition is three fields read like a sentence: column — condition — value. + Add condition adds one, ✕ removes it. Every condition must be true at the same time (“and”, not “or”). No conditions = every row.

The value field adapts to the column: for a pick list it shows its options, for yes/no — yes and no, and for text it offers a value I type, the current user or their team.

Co robi
  • Set a field to a value — wpisuje wartość w kolumnę (np. Status = Closed, Due = dzisiejsza data, Owner = bieżący użytkownik);

Standard items

Click to switch on or off: Edit row, Duplicate, Add a note, Copy as text, Export selected, Delete row.

Your own actions

An action is a ready-made step done in one click — without opening the row. + Add your own action adds one. Fields:

Label

The text in the menu.

“Close request”

What it does
  • Set a field to a value — writes a value into a column (e.g. Status = Closed, Due = today's date, Owner = current user);
  • Clear a field — empties a column;
  • Duplicate the row — copies the row;
  • Delete the row — deletes it (always asks first);
  • Move to another dataset — moves the row to another dataset (e.g. an archive).
Field and value

Which column to set and to what. Dates offer today’s date, text offers the current user and their team, and you can always type your own value (a value I type).

Ask before running

Shows a question with an Apply button before running. Turn it on for actions that are easy to click by mistake.

Works on many rows at once If you tick several rows and right-click one of them, the action runs on all the ticked rows. Right-clicking a row outside the selection runs it on that one row only.
