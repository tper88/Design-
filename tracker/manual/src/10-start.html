Tracker builder to kreator, w którym bez programowania składasz własny tracker do codziennej pracy — rejestr zgłoszeń, listę zadań, terminy, notatki — zamiast prowadzić to w Excelu.

Na końcu kreator daje Ci jeden plik HTML. Otwierasz go w przeglądarce i pracujesz: dodajesz wiersze, filtrujesz, patrzysz na wykresy, eksportujesz do Excela. Działa bez internetu, a dane zapisuje w pliku na Twoim dysku — nic nie wysyła na żaden serwer.

Ta instrukcja prowadzi od zera. Jeśli robisz to pierwszy raz, przeczytaj ten rozdział i od razu przejdź do rozdziału 2 — w 10 minut zbudujesz działający tracker. Resztę czytaj wtedy, gdy będziesz czegoś potrzebować.

Etykiety na ekranie są po angielsku Kreator i tracker mówią po angielsku. W tej instrukcji przyciski i pola są cytowane dokładnie tak, jak je zobaczysz, w ramce — na przykład Next →. Szukaj na ekranie dokładnie tego napisu.

Tracker builder is a wizard where you put together your own work tracker — a request log, a task list, deadlines, notes — without writing any code, instead of keeping it all in Excel.

At the end the wizard gives you one HTML file. You open it in your browser and work: add rows, filter them, look at charts, export to Excel. It works without an internet connection and saves your data in a file on your own disk — nothing is sent to any server.

This guide starts from zero. If this is your first time, read this chapter and go straight to chapter 2 — in 10 minutes you will have a working tracker. Read the rest when you need it.

Everything revolves around four files. Understand this one map and you will avoid 90% of problems.

FileWhat it isWhat to do with it
tracker-wizard.htmlThe wizard. The same file for everyone.Open it when you want to build a new tracker or change an existing one.
Name.htmlYour tracker. The name comes from the Tracker name field.Open it every day. Do not rename or move it unless you have to.
Name.tracker.jsonThe tracker's structure: columns, tabs, components, style. No data.Keep it next to the tracker. Without it, changing the tracker means building it again.
Name.data.jsonYour data — every row, note, checklist item and your profile.The most valuable file. The tracker creates it on first use. Back it up.
The simplest rule Keep the last three files together in one folder, e.g. Documents\Trackers\Requests, and leave them there. The wizard can live anywhere.

  • No internet connection is needed. When there is one, the tracker loads nicer fonts; without it, it uses the system fonts and works the same.
How to open an HTML file in Chrome Right-click the file → Open with → Google Chrome (or Microsoft Edge). You can also drag the file onto an open browser window.

Zbudujemy rejestr zgłoszeń z gotowego szablonu, wygenerujemy go i wpiszemy pierwszy wiersz. Każdy krok zrób dokładnie tak, jak jest opisany.

  1. Otwórz kreator. Otwórz tracker-wizard.html w Chrome. Zobaczysz ekran Let’s start z trzema kafelkami.
  2. Wybierz szablon. Kliknij kafelek Request log. Kreator sam przejdzie do kroku Basics. Szablon ma już kolumny, zakładki, wykresy i alerty — nie musisz niczego dodawać.
  3. Nadaj nazwę. W polu Tracker name wpisz nazwę, np. Zgłoszenia działu. Od niej będą nazywać się pliki.
  4. Wybierz format i styl. W Number and date format wybierz Polish — 31.12.2026 · 1 234,56, jeśli w Excelu używasz polskich liczb i dat. Niżej kliknij jeden z pięciu kafelków stylu — to tylko wygląd.
  5. Przejdź na koniec. W lewym pasku kliknij Review & export. Jeśli wszystko jest w porządku, nie zobaczysz czerwonej ramki z problemami.
  6. Zapisz oba pliki. Kliknij Download tracker (.html), wskaż folder (np. nowy folder Trackery) i zapisz. Potem kliknij Download structure (.tracker.json) i zapisz w tym samym folderze.
  7. Otwórz tracker. Zamknij kreator. W folderze otwórz nowy plik Zgłoszenia działu.html w Chrome. U góry zobaczysz żółty baner Your data is not being written to a file — to normalne przy pierwszym otwarciu.
  8. Utwórz plik danych. Kliknij Choose a data file, a w okienku Create a new data file. Zapisz plik w tym samym folderze (nazwa jest podpowiedziana). Baner zniknie, a u góry pojawi się zielone Saved z godziną.
  9. Dodaj pierwszy wiersz. Wejdź w zakładkę Log, kliknij + Add row, wypełnij pola i kliknij Add row. Gotowe — wiersz jest w tabeli, a za chwilę także w pliku.
Co dalej? Następnego dnia po prostu otwórz ten sam plik .html. Po restarcie przeglądarki tracker raz poprosi o ponowne połączenie z plikiem danych — kliknij Reconnect (patrz 6.3).

We will build a request log from a ready-made template, generate it and enter the first row. Do each step exactly as written.

  1. Open the wizard. Open tracker-wizard.html in Chrome. You will see the Let’s start screen with three tiles.
  2. Pick a template. Click the Request log tile. The wizard moves to the Basics step on its own. The template already has columns, tabs, charts and alerts — you do not need to add anything.
  3. Give it a name. In Tracker name type a name, e.g. Team requests. The files will be named after it.
  4. Pick a format and a style. In Number and date format pick the one you use in Excel — English (UK) — 31/12/2026 · 1,234.56 for day-first dates. Below, click one of the five style tiles — that is only the look.
  5. Go to the end. In the left bar click Review & export. If everything is fine there is no red box with problems.
  6. Save both files. Click Download tracker (.html), choose a folder (e.g. a new folder Trackers) and save. Then click Download structure (.tracker.json) and save it in the same folder.
  7. Open the tracker. Close the wizard. In the folder, open the new file Team requests.html in Chrome. At the top there is a yellow banner, Your data is not being written to a file — that is normal the first time.
  8. Create the data file. Click Choose a data file, then Create a new data file. Save it in the same folder (the name is suggested). The banner disappears and a green Saved with the time shows at the top.
  9. Add the first row. Open the Log tab, click + Add row, fill in the fields and click Add row. Done — the row is in the table and, a moment later, in the file.
What next? Tomorrow, just open the same .html file. After a browser restart the tracker asks once to reconnect to the data file — click Reconnect (see 6.3).

Kilka słów wraca w kreatorze na każdym kroku. Każde wyjaśniam na przykładzie rejestru zgłoszeń.

Dataset (zbiór danych)

Jedna tabela: kolumny i wiersze. Jak jeden arkusz w Excelu.

Zbiór Requests — wszystkie zgłoszenia.

Column (kolumna)

Jedna informacja o każdym wierszu. Ma nazwę i typ.

Subject, Due, Status.

Row (wiersz)

Jeden wpis w zbiorze — w trackerze dodajesz go przyciskiem + Add row.

Jedno zgłoszenie: „Korekta faktury, termin 10.10, w toku”.

Column type (typ kolumny)

Mówi trackerowi, co jest w kolumnie: tekst, liczba, data, lista wyboru albo tak/nie. Od typu zależy, jakie pole zobaczysz przy wpisywaniu, jak działa sortowanie i co trafia do Excela.

Pick list (lista wyboru)

Kolumna, w której wybierasz jedną z ustalonych opcji, a nie piszesz dowolnie. Każda opcja może mieć kolor.

Status: New (niebieski), In progress (żółty), Closed (zielony).

Tab (zakładka)

Jedna strona trackera, widoczna w lewym pasku.

Summary, Log, Dates, Notes.

Component (komponent)

Klocek na zakładce: tabela, licznik (KPI), wykres, pasek postępu, baner, agenda, karteczki albo checklista.

Filter (filtr)

Warunki, które wybierają tylko część wierszy. Wszystkie warunki muszą być spełnione jednocześnie.

„Status is not Closed” i „Due — overdue” = zgłoszenia otwarte po terminie.

Quick filter chip (szybki filtr)

Przycisk nad tabelą, który jednym kliknięciem włącza gotowy filtr. Drugie kliknięcie go wyłącza.

Open, Overdue, Mine.

Alert

Reguła, która liczy wiersze i pokazuje ostrzeżenie pod dzwonkiem, gdy jest ich za dużo.

„Więcej niż 0 zgłoszeń po terminie”.

Preset (szablon zakładki)

Gotowy typ zakładki, który sam dobiera komponenty do Twoich kolumn.

@user, @team, @today

Specjalne wartości: „imię osoby, która używa trackera”, „jej zespół” i „dzisiejsza data”. Tracker podstawia je w chwili użycia, więc „Mine” u każdego pokazuje jego wiersze.

A few words come back at every step of the wizard. Each one is explained with the request log as the example.

Dataset

One table: columns and rows. Like one sheet in Excel.

The dataset Requests — every request.

Column

One piece of information about every row. It has a name and a type.

Subject, Due, Status.

Row

One entry in a dataset — in the tracker you add one with + Add row.

One request: “Invoice correction, due 10 Oct, in progress”.

Column type

Tells the tracker what the column holds: text, a number, a date, a pick list or yes/no. The type decides which input you get when typing, how sorting works and what lands in Excel.

Pick list

A column where you choose one of a fixed set of options instead of typing freely. Each option can have a colour.

Status: New (blue), In progress (amber), Closed (green).

Tab

One page of the tracker, listed in the left bar.

Summary, Log, Dates, Notes.

Component

A building block on a tab: a table, a counter (KPI), a chart, a progress bar, a banner, an agenda, sticky notes or a checklist.

Filter

Conditions that pick out only some rows. Every condition must be true at the same time.

“Status is not Closed” and “Due — overdue” = open requests past their due date.

Quick filter chip

A button above a table that switches a ready-made filter on with one click. A second click switches it off.

Open, Overdue, Mine.

Alert

A rule that counts rows and shows a warning under the bell when there are too many.

“More than 0 requests past their due date”.

Preset

A ready-made kind of tab that picks components to match your columns.

@user, @team, @today

Special values: “the name of the person using the tracker”, “their team” and “today’s date”. The tracker fills them in when they are used, so “Mine” shows each person their own rows.
