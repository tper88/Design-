Want to add a column, change a chart or the style? Do not start again — load the structure.

  1. Open tracker-wizard.html. In the Already have a tracker and want to change it box, load Name.tracker.json.
  2. Make your changes in any step.
  3. In Review & export click Download tracker (.html) and save it in the same folder, under the same name — agree to replace the old file.
  4. Save Download structure (.tracker.json) the same way, replacing the old one.
  5. Open the tracker. Your data is there, and a one-time notice at the top says what changed.
ChangeSafe?
Renaming a column, tab or componentYes — always.
A new column, tab, component or alertYes. A new column is empty in old rows.
Style, number and date format, currencyYes.
Deleting a columnThe data is hidden, not erased — it comes back if you add the column back (the same one, not a new one with the same name). Check filters that used it.
Changing a column's typeCarefully: old values that do not fit get a dotted underline.
Changing a pick list option's valueNo — rows with the old value stop matching. Change the label instead.
Do not rebuild from a template A tracker rebuilt from a tile is a different tracker to the browser. When opening your data file you will see This file belongs to another tracker, and some rows may not show. Always change a tracker by loading its .tracker.json.

Tracker to plik na dysku, a nie aplikacja w chmurze. To ważne, gdy korzysta z niego więcej osób.

  • Ten sam tracker, osobne dane (zalecane): wyślij kolegom plik .html. Każdy przy pierwszym otwarciu wybiera Create a new data file i ma swój plik danych.
  • Przekazanie danych: wyślij swój .data.json. Odbiorca otwiera tracker i wybiera Open my existing data file. Od tej chwili każdy pracuje na swojej kopii.
  • Wspólny plik na dysku sieciowym: działa, ale nie dla dwóch osób naraz. Tracker sprawdza zmiany w pliku tylko przy otwarciu i przy Reconnect — jeśli dwie osoby piszą jednocześnie, wygrywa ta, która zapisze ostatnia. Umówcie się, kto i kiedy pracuje.
  • Każdy ma własny profil — imię i zespół ustawione na jego komputerze nie nadpisują profilu kolegi.

The tracker is a file on a disk, not a cloud app. That matters when more than one person uses it.

  • Same tracker, separate data (recommended): send colleagues the .html file. On first opening each of them chooses Create a new data file and has their own data file.
  • Handing over data: send your .data.json. The recipient opens the tracker and chooses Open my existing data file. From then on each of you works on your own copy.
  • A shared file on a network drive: it works, but not for two people at once. The tracker checks for changes to the file only when it opens and on Reconnect — if two people write at the same time, whoever saves last wins. Agree who works when.
  • Everyone has their own profile — the name and team set on one computer do not overwrite a colleague's.

Częste pytania

Nowy komputer — jak przenieść tracker?

Skopiuj folder z plikami .html i .data.json. Otwórz tracker, Choose a data file → Open my existing data file → wskaż .data.json.

Przeniosłem albo przemianowałem plik trackera i „zniknęły dane”

Nie zniknęły — są w .data.json. Przeglądarka zapomniała tylko, gdzie jest plik. Choose a data file → Open my existing data file.

Coś skasowałem i chcę wrócić do wczoraj

Tracker nie ma przycisku „cofnij”. Jeśli masz kopię z Save a JSON backup, użyj Load data from a JSON file…. Dlatego rób kopie regularnie — albo kopiuj cały folder.

Zamknąłem kreator i straciłem pracę

Kreator nie zapisuje sam. Następnym razem zapisuj Download structure (.tracker.json) co jakiś czas.

Filtr „Mine” nic nie pokazuje

W profilu (6.10) wpisz imię dokładnie tak, jak w kolumnie opiekuna.

Wklejone daty mają zamieniony dzień z miesiącem

Format w Basics nie zgadza się z Twoim Excelem. Zmień go, wygeneruj tracker ponownie (8) i wklej jeszcze raz.

Kalendarz przy polu daty pokazuje inny format niż tabela

Okienko kalendarza należy do przeglądarki i używa ustawień językowych komputera. Tabela i eksport i tak używają formatu wybranego w kreatorze.

Frequent questions

A new computer — how do I move the tracker?

Copy the folder with the .html and .data.json files. Open the tracker, Choose a data file → Open my existing data file → pick the .data.json.

I moved or renamed the tracker file and “the data is gone”

It is not gone — it is in the .data.json. The browser only forgot where the file is. Choose a data file → Open my existing data file.

I deleted something and want yesterday back

The tracker has no undo button. If you have a copy from Save a JSON backup, use Load data from a JSON file…. That is why you should back up regularly — or copy the whole folder.

I closed the wizard and lost my work

The wizard does not save by itself. Next time save Download structure (.tracker.json) now and then.

The “Mine” filter shows nothing

In your profile (6.10) type your name exactly as it appears in the owner column.

Pasted dates have day and month swapped

The format in Basics does not match your Excel. Change it, generate the tracker again (8) and paste once more.

The calendar on a date field shows a different format from the table

The calendar pop-up belongs to the browser and follows the computer's language settings. The table and the export still use the format chosen in the wizard.

Żeby nie szukać czegoś, czego nie ma:

  • Nie jest wspólną aplikacją w chmurze — dwie osoby nie pracują na żywo na tym samym pliku (9).
  • Nie ma przycisku „cofnij” — rób kopie (Save a JSON backup).
  • Nie powiadamia, gdy jest zamknięty — alerty widać tylko w otwartym trackerze, nic nie jest wysyłane mailem.
  • Nie liczy formuł w kolumnach — sumy i średnie dają komponenty (KPI, wykres, wiersz sum).
  • Nie łączy warunków przez „lub” — filtr to zawsze „i” (5.9).
  • Nie ma kalendarza w widoku miesiąca — jest agenda, czyli lista terminów.
  • Nie importuje pliku .xlsx — dane przenosisz, kopiując z Excela i wklejając (6.7).
  • Nie działa na telefonie — tylko Chrome lub Edge na komputerze.

So you do not go looking for something that is not there:

  • It is not a shared cloud app — two people cannot work live on the same file (9).
  • It has no undo button — make backups (Save a JSON backup).
  • It does not notify you when closed — alerts show only in the open tracker; nothing is emailed.
  • It does not calculate formulas in columns — sums and averages come from components (KPI, chart, totals row).
  • It does not combine conditions with “or” — a filter is always “and” (5.9).
  • It has no month-grid calendar — there is the agenda, a list of dates.
  • It does not import .xlsx files — you move data by copying from Excel and pasting (6.7).
  • It does not work on phones — Chrome or Edge on a computer only.
